# 遙控封包格式（UDP）

遙控器（`rc_d1mini`）與飛控（`fc_wt32eth01`）之間的通訊格式。
程式定義在兩個專案的 `protocol.h`，兩份必須完全一致；修改格式時請遞增 `LINK_VERSION`。

目前版本：**`LINK_VERSION = 1`**

## 傳輸方式

| 項目 | 值 |
|---|---|
| 協定 | UDP（IPv4） |
| 飛控接收埠 | `4210`（`LINK_UDP_PORT`，遙控器網頁可改目標埠） |
| 遙控器接收埠 | `4211`（`LINK_LOCAL_PORT`，控制封包也從這個埠送出） |
| 控制封包頻率 | 50Hz（每 20ms，`LINK_SEND_HZ`） |
| 遙測封包頻率 | 20Hz（每 50ms，`TELEMETRY_PERIOD_MS`） |
| 封包長度 | 兩種封包都是固定 **16 bytes** |
| 位元組順序 | **Little-endian**（ESP32 原生順序），結構無填充（`packed`） |

### 目標位址

遙控器依下列順序決定控制封包送往哪裡：

1. 網頁「飛控連線」有填 IP → 固定送到該 IP，也只接受該 IP 的遙測。
2. 未填 IP，且 3 秒內收過遙測 → 送到回應遙測的飛控 IP（自動學習）。
3. 其他情況 → 廣播到 `255.255.255.255`。

飛控把遙測送回「最後一個控制封包的來源 IP 與埠」。

### 遙控器鎖定

飛控收到第一個合法控制封包後，會鎖定該來源 IP。之後其他 IP 送來的封包一律忽略，直到鎖定的遙控器斷線超過 3 秒（`LINK_PEER_HOLD_MS`）。

## 控制封包 `CtrlPacket`（遙控器 → 飛控）

| 偏移 | 型別 | 欄位 | 說明 |
|---:|---|---|---|
| 0 | `uint16` | `magic` | 固定 `0x4346`（線上位元組 `46 43`，即 ASCII `"FC"`） |
| 2 | `uint8` | `version` | `1` |
| 3 | `uint8` | `flags` | bit0 `CTRL_FLAG_ARM`：解鎖開關 ON；其餘位元保留為 0 |
| 4 | `uint16` | `seq` | 序號，每送一包加 1，溢位後回到 0 |
| 6 | `uint16` | `throttle` | 油門 `0`～`1000` |
| 8 | `int16` | `roll` | `-500`～`500`，正 = 向右傾 |
| 10 | `int16` | `pitch` | `-500`～`500`，正 = 桿往前推（低頭前進） |
| 12 | `int16` | `yaw` | `-500`～`500`，正 = 機頭向右轉 |
| 14 | `uint16` | `crc` | 前 14 bytes 的 CRC，見下方 |

飛控收到後會再把數值夾在合法範圍內（油門上限 1000，三軸 ±500）。

搖桿值在飛控上的對應：

| 欄位 | 滿舵 ±500 對應 |
|---|---|
| `roll` | ±「最大傾角」（預設 25°） |
| `pitch` | ±「最大傾角」，方向相反：前推 = 低頭 |
| `yaw` | ±「最大偏航速率」（預設 150°/s） |

## 遙測封包 `TelemPacket`（飛控 → 遙控器）

| 偏移 | 型別 | 欄位 | 說明 |
|---:|---|---|---|
| 0 | `uint16` | `magic` | 固定 `0x4C54`（線上位元組 `54 4C`，即 ASCII `"TL"`） |
| 2 | `uint8` | `version` | `1` |
| 3 | `uint8` | `flags` | 見下表 |
| 4 | `uint16` | `ackSeq` | 飛控最後收到的 `CtrlPacket.seq` |
| 6 | `int16` | `roll` | 單位 0.1°，正 = 右側向下 |
| 8 | `int16` | `pitch` | 單位 0.1°，正 = 抬頭 |
| 10 | `int16` | `yawRate` | 單位 °/s，正 = 機頭向右 |
| 12 | `uint16` | `vbat` | 電池電壓，單位 mV；`0` = 未接電壓偵測 |
| 14 | `uint16` | `crc` | 前 14 bytes 的 CRC |

`flags` 位元：

| 位元 | 名稱 | 意義 |
|---:|---|---|
| 0 (`0x01`) | `TELEM_FLAG_ARMED` | 飛控已解鎖 |
| 1 (`0x02`) | `TELEM_FLAG_FAILSAFE` | 失控保護中 |
| 2 (`0x04`) | `TELEM_FLAG_IMU_OK` | IMU 正常 |
| 3 (`0x08`) | `TELEM_FLAG_LOCKOUT` | 系統鎖定（OTA、重新啟動或校正中），不允許解鎖 |

## CRC

**CRC-16/CCITT-FALSE**：

| 參數 | 值 |
|---|---|
| 多項式 | `0x1021` |
| 初始值 | `0xFFFF` |
| 輸入／輸出反轉 | 無 |
| 最終 XOR | 無 |
| 檢查值 | `"123456789"` → `0x29B1` |

計算範圍是封包前 14 bytes（`crc` 以外的所有欄位），結果以 little-endian 存在最後 2 bytes。

```c
uint16_t crc = 0xFFFF;
for (each byte b) {
  crc ^= b << 8;
  for (int i = 0; i < 8; i++) crc = (crc & 0x8000) ? (crc << 1) ^ 0x1021 : crc << 1;
}
```

## 接收端驗證

封包要符合下列全部條件才會被接受，否則直接丟棄：

1. 長度剛好 16 bytes。
2. `magic` 正確。
3. `version == LINK_VERSION`。
4. `crc` 正確。
5. 來源 IP 符合鎖定規則（飛控鎖定遙控器；遙控器有設定固定 IP 時只收該 IP）。

## 逾時

| 一方 | 條件 | 結果 |
|---|---|---|
| 飛控 | 500ms 沒收到控制封包（`LINK_TIMEOUT_MS`） | 進入失控保護：保持水平，3 秒內油門降到 0 後上鎖 |
| 飛控 | 斷線超過 3 秒 | 解除遙控器 IP 鎖定 |
| 遙控器 | 1 秒沒收到遙測 | OLED 與網頁顯示「未連線」 |
| 遙控器 | 3 秒沒收到遙測 | 自動模式下改回廣播 |

## 解鎖規則（與封包相關的部分）

- 飛控只在 `CTRL_FLAG_ARM` 由 0 變 1 的那一刻嘗試解鎖，而且當時 `throttle < 50`。
- 開機或連線恢復時，開關若已在 ON，不會解鎖；必須先送 0 再送 1。
- 已解鎖時收到 `CTRL_FLAG_ARM = 0`，會立即上鎖。

## 範例

### 控制封包

內容：解鎖開關 ON、`seq` 1234、油門 500、roll -100、pitch 250、yaw 0。

```
46 43 01 01 D2 04 F4 01 9C FF FA 00 00 00 A9 15
```

| bytes | 欄位 | 值 |
|---|---|---|
| `46 43` | magic | `0x4346` |
| `01` | version | 1 |
| `01` | flags | ARM |
| `D2 04` | seq | 1234 |
| `F4 01` | throttle | 500 |
| `9C FF` | roll | -100 |
| `FA 00` | pitch | 250 |
| `00 00` | yaw | 0 |
| `A9 15` | crc | `0x15A9` |

### 遙測封包

內容：已解鎖且 IMU 正常（flags `0x05`）、`ackSeq` 1234、roll +3.2°、pitch -1.5°、yaw -3°/s、11.84V。

```
54 4C 01 05 D2 04 20 00 F1 FF FD FF 40 2E 15 73
```
